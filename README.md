Smart Task Delegator

Smart Task Delegator is a web-based productivity and collaboration platform built for teams and hackathons. The frontend is developed using HTML, CSS, and JavaScript, featuring modules like task management, smart task assignment, quick notes, and a hackathon starter kit.

The backend is powered by Flask and integrates Firebase Realtime Database using Firebase Admin SDK. It provides APIs for adding users, managing team availability, and intelligently assigning tasks based on skills, workload, and time slots.

The project supports real-time updates, authentication via Firebase, and a clean separation of frontend and backend for scalability.
